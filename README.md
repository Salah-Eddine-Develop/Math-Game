# Math Quiz Game (C++)

A lightweight, interactive C++ console application designed to test and improve basic arithmetic skills. The game dynamically generates random math problems based on user-selected difficulty levels and operation types.

---

## 🌟 Key Features

- **Custom Difficulty Levels:** Choose between Easy, Medium, Hard, or a Mix of all levels.
- **Operation Selection:** Practice Addition, Subtraction, Multiplication, Division, or a Random Mix.
- **Visual & Audio Feedback:** Real-time console screen color changes (Green for correct answers, Red with a beep for wrong answers).
- **Game Summary:** Detailed end-of-game statistics showing total questions, right vs. wrong answers, and overall Pass/Fail status.
- **Replay Functionality:** Option to restart and play multiple rounds without restarting the program.

## 🚀 Getting Started

### Prerequisites

You need a C++ compiler installed on your system, such as:

- GCC / G++
- Clang
- MSVC

### How to Run

1. Download the repository.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated executable.

---

## 🎮 Game Flow

1. Choose the number of questions.
2. Select the difficulty level.
3. Select the operation type.
4. Answer the generated questions.
5. Receive immediate feedback.
6. View your final results.
7. Choose whether to play again.
